# SRCMG 人工评价问卷

将原始 `evaluation.html` 中的人工评价协议整理为可公开访问、可离线填写的逐题问卷。页面无需后端、账号、第三方 CDN 或构建步骤。

**在线填写：[SRCMG 人工评价问卷](https://wayne-0213.github.io/SRCMG/human-evaluation/)**

## 评价协议

- 50 道题：原页面中 Java、Python 样本各 25 道；每题 5 条候选消息，共 250 条。
- 每题展示代码变更、真实提交消息，以及已打乱顺序的候选消息 A–E。
- 三个维度均采用 1–5 分，越高越好：信息充分性（反映重要变更信息的程度）、简洁性（冗余越少越好）、表达性（语法正确性与语言流畅性）。总分为三个维度的平均分。
- 可接受性：是否愿意采用该候选消息作为最终提交消息；接受为 `1`，不接受为 `0`。
- 原页面的样本、题号、候选顺序、参考消息、代码变更和随机种子 `20260407` 均保留，没有重新抽样或改写消息。语言标签沿用原实验数据；个别变更可能包含该项目的其他文件类型。
- 页面仅显示候选标签，作答过程中不展示方法名。**方法映射包含在公开源码及导出明细中**，属于界面层面的盲评，不能阻止参与者查看源码。正式研究中应要求参与者在完成评分前不查看映射或导出统计。

## 填写与交回结果

1. 打开问卷，展开“填写前，请了解评价标准”。评价者编号选填，建议使用研究组织者分配的匿名编号。
2. 按组织者安排设置本次评价题数。`15` 表示填写前 15 题，默认全部 50 题。缩小范围不会删除范围之外的已填答案。
3. 逐题为每条候选消息填写三个分数和是否接受。左侧/顶部导航显示未填、已开始、已完成和当前题目，可随时跳转。
4. 答案随操作自动保存到当前浏览器；重新打开同一地址可继续。跨设备或浏览器时，使用“下载与备份 → 下载草稿 JSON / 导入草稿”。旧页面导出的明细 JSON 或含 `responses` 的草稿也可导入；统计文件不能恢复作答。
5. 全部完成所选范围后，点击“完成并导出”，或“下载与备份 → 导出完整明细 JSON”。缺失评分会定位到相应题目；中途保存请使用草稿下载。
6. 将 `evaluation_results_*.json` 按组织者指定的渠道交回。需要查看汇总时，可另行导出统计 CSV 或 JSON。

**页面不会自动上传或集中收集答案。** 不会向 GitHub 写入评价结果，也不收集姓名、邮箱、IP 或分析事件。不要将包含真实身份或个人回答的文件提交到公开仓库。浏览器清理站点数据、隐私模式或存储空间不足可能影响本地保存，请及时下载草稿备份。本地文件与在线地址的草稿相互独立。

## 本地运行

下载/克隆仓库后，直接用浏览器打开本目录的 `index.html`，保持 `styles.css`、`data.js`、`app.js` 位于同一目录。推荐使用本地 HTTP 服务获得一致的存储行为，在仓库根目录运行：

```sh
python -m http.server 8000
```

然后访问 [本地问卷](http://localhost:8000/docs/human-evaluation/)。无需安装前端运行依赖。

仓库通过 GitHub Pages 的 `main` 分支 `/docs` 目录发布，问卷路径为 `/human-evaluation/`。更新静态文件并提交后即可更新在线版本；Pages 的源目录可在仓库 Settings → Pages 中查看。

## 数据与导出格式

`data.js` 是从用户指定的原始 `evaluation.html` 精确提取的问卷快照，不包含任何参与者作答。`meta.dataset_id` 是题目内容的 SHA-256 前 16 位，用于隔离不同版本的本地草稿；原始 `generated_at`、抽样参数及方法列表均保留，生成机器的绝对路径已移除。

明细 JSON 与原页面保留相同的顶层结构：

| 字段 | 含义 |
| --- | --- |
| `meta` | 评价者编号、导出时间、样本来源参数、问卷版本、导出范围 |
| `responses` | 每条候选的题号、语言、commit、候选标签、方法、候选/参考消息、三个评分、平均分、可接受性 |
| `summary.overall` | 评价项总数、完整项数、完成率 |
| `summary.by_method` | 按方法汇总的完整项数、各维度均分、总均分、接受率 |
| `summary.by_question` | 按题号分组的明细 |

草稿备份额外包含全部已填 `answers`、当前题目和题数设置，未答字段不预填。明细和统计导出要求范围内所有条目完整填写；平均分保留 4 位小数，接受率为接受条目占完整条目的比例，CSV 使用 UTF-8 BOM 方便 Excel 打开。

## 重新提取问卷

在仓库根目录运行，输入文件需包含原生成器的 `evaluationData` 和 `evaluationMeta`：

```sh
python tools/prepare_human_evaluation.py /path/to/evaluation.html
```

也可用 `--output` 指定目标 `data.js`。脚本只读取指定 HTML，不扫描或发布原目录中的评价者结果。题目内容变化会产生新的数据版本和独立草稿存储，避免把不同样本的评分混在一起。

## 验证

在本目录运行以下命令。Playwright 仅为可选的开发测试依赖，不参与页面运行：

```sh
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node tests/smoke.cjs
```

测试会启动临时静态服务，检查桌面/手机布局、全部题目导航、未完成校验、自动保存恢复、完整评分、JSON/CSV 统计、草稿导入、旧版兼容和离线加载。
